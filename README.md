## ✨ Features

- **Arithmetic operations** — `+` `-` `×` `÷`
- **Scientific basics** — essential math functions
- **iOS-inspired UI** — smooth, native feel
- **Fully responsive** — works on any screen size

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/m1rzo99/Calculate-main.git

# Install dependencies
npm install

# Run dev server
npm run dev
```
